## Verdict

**PASS.** max |ΔΣ_X(k, n)| = **0.090 meV** across all 9 k-points × 56 bands = 504 (k, n) pairs. Pass gate was ≤ 1 meV; observed residual is **11× below threshold**, consistent with floating-point and DFT-eigenvalue ULP noise (the two WFNs were generated by independent SCF runs and differ by ~0.1 meV in eigenvalues).

## Test design

Two LORRAX cohsex runs on the SAME Phase-2 code, using the SAME orbit-closed 399-centroid file, differing only in the symmetry of the input WFN:

| run | WFN source | ntran | sym ops | k-points | unfold path exercised |
|-----|------------|-------|---------|----------|----------------------|
| `run_sym/`   | `00_mos2_3x3_cohsex/qe/nscf/WFN.h5`  | 2 | E + σ_h | 9 (all explicit) | PR1 find_irreducible_bz_points → PR2 unfold_v_q → PR3 unfold_psi + iσ_y·conj on TRS rows |
| `run_nosym/` | `02_mos2_3x3_nosym/qe/nscf/WFN.h5`   | 1 | E only  | 9 (all explicit) | trivial: IBZ ≡ full BZ, no unfold work |

**TRS-fold k-points** in the sym WFN: `{1, 3, 4, 5}` (4 of 9). These are the rows where the sym-augmented half of the sym group acts via complex conjugation, and where PR3's iσ_y·conj rotation on `U_spinor[ntran + s]` and PR3's τ-phase fix on `_get_umklapp_vector` apply.

**cohsex.in**: identical between runs except for the WFN file (linked). `x_only=true`, `do_screened=false`, `bispinor=false`, `bare_coulomb_cutoff=30.0` Ry explicit, `nval=26`, `ncond=30`, `nband=56`.

### TRS vs non-TRS group statistics (Σ_X column, meV)

```
TRS k-points {1,3,4,5}     :  N=224  max|ΔΣ_X|=0.0900  mean|ΔΣ_X|=0.0283  stddev=0.0303
non-TRS k-points {0,2,6,7,8}: N=280  max|ΔΣ_X|=0.0900  mean|ΔΣ_X|=0.0299  stddev=0.0325
```

**The TRS-fold and non-TRS-fold k-points have indistinguishable residual distributions.** This is exactly the signature of a correct symmetry implementation: the unfold path produces the same answer as direct evaluation. Any leftover PR3-style bug (~50–100 meV) would have shown up as a 1000× shift in the TRS group vs non-TRS group; instead we see 0.028 vs 0.030 meV mean — within ULP of each other.

## Phase-2 baseline confirmation

The PR2-vs-PR3 audit (`reports/trs_sym_audit_2026-05-14/audit_pr3.md`, R3 finding) showed PR3 shifts Σ_X by up to 95 meV on this exact MoS₂ 3×3 SOC system relative to PR2 — confirming the bug PR3 fixes WAS firing on this test bed. The sym-vs-nosym comparison reported here directly verifies that **PR3's fix produces the *physically correct* answer**: bit-equal (to ULP) to the ground-truth nosym evaluation, where no unfold runs and no opportunity exists for the TRS-rotation bug to fire.
